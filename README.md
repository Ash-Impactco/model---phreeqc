# Ilha Carbon: Lomba da Maia basalt rate trial model

Soil and geological model for an enhanced rock weathering (basalt) rate trial on pasture at Lomba da Maia, Sao Miguel, Azores.

**Status, November 2026:** fresh base. The plot layout and trial design are ready; soil and rock values are empty until the December soil screening and the feedstock analyses are loaded. Nothing here is a site result.

Everything is in [`ilha_erw_model/`](ilha_erw_model/); start with its README.
